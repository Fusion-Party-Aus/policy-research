## Corpus snapshot

The `corpus/` directory contains a snapshot of the Victorian policy and research corpus retrieved from the public Sanity JSON API:

- [Corpus manifest](corpus/MANIFEST.md) — reconciles every source item to its imported location
- [Retrieval log](corpus/RETRIEVAL-LOG.md) — provenance, timestamps and hashes
- `corpus/policies.json` — 41 adopted policies (raw API snapshot)
- `corpus/research.json` — 25 research resources (raw API snapshot)

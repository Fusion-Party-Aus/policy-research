# Fusion Policy Research

An open, version-controlled workspace for research and working papers across Fusion Party branches.

> **Research is not automatically endorsed party policy.** Documents here may be drafts, evidence reviews, alternative options or critiques. Formal policy adoption follows the relevant party processes.

## For first-time contributors

Open the appropriate state folder, choose **Add file → Create new file**, name your file (for example `accessible-public-transport.md`), and paste your draft. Propose your change using a branch and pull request. You don't need VS Code to get started.

Papers should identify author(s), jurisdiction, status, last review date and sources. Merge into this repository means a document is available for collaboration; it does **not** imply endorsement.

## Existing research

This is a new collaborative workspace, not a replacement for existing research repositories or live websites. Link or import older work deliberately, preserving provenance and permissions.

# Queensland research

Workspace for Queensland-focused evidence reviews, proposals and policy critiques.

**Start here, Stewart:** You can add a Markdown file directly in GitHub. Choose **Add file → Create new file** while viewing this folder, enter a descriptive filename such as `accessible-public-transport.md`, paste your paper, and propose it through a pull request. See [contributing](../CONTRIBUTING.md) and the optional [template](../templates/research-brief.md).

## Initial research areas (not adopted policies)

- Public transport accessibility, service coverage, reliability and fares.
- Land use, housing and access to essential services.
- Local government, regional equity and implementation feasibility.

These are **research prompts**, not positions attributed to the Queensland branch or to any contributor. Authors decide what to investigate and document the evidence.
